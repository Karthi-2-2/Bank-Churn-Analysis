# Bank-Churn-Analysis
Project Overview

This project focuses on analyzing customer churn data to understand customer behavior and identify factors that contribute to customer churn.

Tools Used
SQL
Python(Colab)
Power BI
Excel

# Key Metrics
Total Customers: 10,000
Churned Customers: 2,670
Churn Rate: 26.7%
Average Monthly Charges: 70.45

# Dashboard Features
Churn Distribution
Contract vs Churn
Payment Method Analysis
Senior Citizen Analysis
Tenure Analysis
Interactive Filters

# Key Insights
Churn Rate is 26.7%.
Contract type influences customer churn behavior.
Customer tenure is related to churn patterns.
Payment methods show varying churn distributions.
